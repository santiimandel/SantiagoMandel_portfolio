# Santiago Mandel — Portfolio

3D artist & creative technologist from Argentina. One-page portfolio with live Three.js viewers.

- **SH010 · Hector's wheelchair**: hard-surface prop, Blender + Substance Painter, two UDIM tiles, rendered live in the browser.
- **SH020 · Eladio**: original character, modeled, textured and rigged.
- **SH030 · Kara**: character render (fan art).
- **SH040 · Logo build-up**: After Effects motion study.
- Showreel 2026.

## Run locally

Static site, no build step. Serve the folder with any static server, e.g. `python3 -m http.server 8000`, then open http://localhost:8000. Opening index.html straight from disk won't load the 3D models (browsers block fetch on file://).

## Stack

Plain HTML, CSS and JavaScript · three.js r147 from jsDelivr · models exported from Blender as glTF.

Fan art pieces are personal studies, not affiliated with their original rights holders.
